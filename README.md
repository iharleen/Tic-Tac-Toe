# 🎮 Tic Tac Toe – Python Mini Project

A simple command-line Tic Tac Toe game developed using Python. The game allows two players to play against each other on a 3×3 board, taking turns to mark their positions with **X** and **O**.

## 📌 Project Overview

Tic Tac Toe is a classic two-player game where players take turns placing their symbols on a 3×3 grid. The objective is to get three of your symbols in a horizontal, vertical, or diagonal line before your opponent.

This project is developed to practice basic Python programming concepts and understand game logic.

## ✨ Features

- Two-player gameplay.
- Interactive 3×3 game board.
- Players take turns marking their positions.
- Checks for winning combinations (rows, columns, and diagonals).
- Detects a draw when all positions are filled.
- Prevents players from selecting already occupied positions.
- Displays the final game result.

## 🎯 How to Play

1. The game starts with an empty 3×3 board.
2. Player 1 is assigned **X**, and Player 2 is assigned **O**.
3. Players take turns entering their chosen position.
4. The first player to get three symbols in a row, column, or diagonal wins.
5. If all nine positions are filled without a winner, the game ends in a draw.
